# Jovem Oportunidade – Parauapebas

Plataforma web que centraliza e divulga oportunidades de capacitação profissional e educacional para jovens da cidade de Parauapebas.

## 📚 Sobre a disciplina

Este projeto foi desenvolvido para a disciplina **Cultura e Sociedade e Tecnologia**, na qual fomos desafiados a usar a tecnologia para resolver um problema real da comunidade.  
Nossa equipe identificou que muitos jovens do ensino médio de Parauapebas desconhecem as diversas oportunidades de formação educacional e profissional oferecidas por instituições e empresas da cidade. Por isso, criamos uma aplicação web que reúne essas informações de forma acessível e centralizada.

## 🎯 Problema

Jovens, principalmente do ensino médio, não têm conhecimento pleno de cursos, vagas de jovem aprendiz, eventos e programas de formação disponíveis em Parauapebas. Isso limita suas escolhas e reduz o acesso a oportunidades que poderiam transformar suas trajetórias.

## 💡 Solução

Uma aplicação web responsiva que:
- Lista cursos, vagas, eventos e exames (como ENEM, vestibulares, cursos técnicos, jovem aprendiz).
- Exibe um mapa com a localização das oportunidades presenciais.
- Apresenta uma seção dedicada às instituições de ensino e empresas parceiras da cidade, com fotos, contatos e endereços.
- Permite que qualquer pessoa adicione novas oportunidades.

## 🛠️ Tecnologias utilizadas

- **HTML5** – estrutura das páginas
- **CSS3** – estilos e design responsivo (mobile-first)
- **JavaScript** – lógica da aplicação, manipulação do DOM, localStorage e integração com mapa
- **Leaflet.js** – mapas interativos
- **Feather Icons** – ícones
- **Git e GitHub** – versionamento de código e colaboração

## 🧑‍🏫 Objetivo pedagógico

Além de resolver o problema da comunidade, o projeto foi pensado para **ensinar desenvolvimento web e versionamento** a alunos recém‑ingressos. Através dele, os participantes puderam aprender na prática:
- Estrutura de um projeto web (HTML, CSS, JS)
- Separação de responsabilidades (arquivos separados)
- Boas práticas de código limpo
- Uso do Git para controle de versão
- Colaboração via GitHub (fork, branch, pull request)
